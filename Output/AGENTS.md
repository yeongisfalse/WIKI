# Output 결과물 규칙

- 이 폴더에는 위키를 바탕으로 만든 재사용 가능한 결과물을 저장한다.
- 당분간 하위 폴더 없이 파일을 저장한다. 파일마다 `type`, `topic`, `status`, `created_at` frontmatter를 둔다.
- 파일 수가 약 50개를 넘거나 탐색이 불편해질 때 유형별 또는 주제별 하위 폴더로 세분화한다.
- 결과물은 결론만 쓰지 말고, 근거가 되는 `wiki/` 페이지 또는 `raw/` 원본을 링크한다.
- 결과물이 새 통찰이나 검증할 가설을 만들면 해당 내용을 `wiki/ideas/` 또는 관련 위키 페이지에도 반영한다.
