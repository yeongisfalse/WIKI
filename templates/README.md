# Web Clipper 템플릿

web-clipper-general.json을 Obsidian Web Clipper 설정에서 Import한다.

- 수집 위치: raw/web/
- raw/web/는 Web Clipper라는 수집 경로를 나타내며, 문서 유형을 확정하지 않는다.
- 템플릿은 capture_type을 web_clipper, document_type을 unknown으로 기록한다.
- ingest 때 학술지·학회 논문과 문헌 리뷰는 wiki/papers/로, Editorial·Commentary·기사·블로그·일반 웹 문서는 wiki/web/로 컴파일한다.
- 원문과 메타데이터만 저장한다.
- Interpreter prompt 변수는 사용하지 않는다.
- AI 요약과 위키 연결은 프로젝트 대화창에서 대기열 처리해줘라고 요청할 때 수행한다.
